# Trained AI Model Weights Directory

Place production-trained cadastral segmentation weights (.onnx, .pt, .pth, .safetensors) in this directory.

Required semantic classes (6 classes):
0 = Background
1 = Building Footprints
2 = Roads & Right-of-Way
3 = Vegetation & Urban Tree Canopy
4 = Water Bodies & Retention
5 = Open Land & Vacant Parcels

When trained weights are absent, UrbanCadastral honestly reports: AI MODEL NOT INSTALLED / AI MODEL NOT AVAILABLE.
